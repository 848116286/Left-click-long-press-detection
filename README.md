# Left-click-long-press-detection
左クリックの長押しを検知できる希望があるデータパックです。

## 対応バージョン
Minecraft JE 26.3
## 内容
lmb_hold_bot:空気中で左クリックの長押しを検知できる軽量なdatapack

lmb_hold_bot_ultimate:処理が重めだが、草の中や梯子の中でも左クリックの長押しを検知できるdatapack

lmb_hold_bot_resourcepack:半径1.5m以内のブロック選択枠線を非表示にするcoreシェーダーと、データパックのアイテムの見た目を変更するresourcepack
