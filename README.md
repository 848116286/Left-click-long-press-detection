# Left-click-long-press-detection
左クリックの長押しを検知できる希望があるデータパックです。
## 対応バージョン
Minecraft JE 26.3
## 使い方
次のコマンドでアイテムを入手することができます。
`/function lmb_hold_bot:give/test_item`

左クリックを長押ししているtick数は、スコアボード`lmbhb.vla`に保存されています
右クリックを長押ししているtick数は、スコアボード`lmbhb.vra`に保存されています

アイテムの検知は`item_model`を使用しているので、見た目を変更するときは、`custom_modl_data`を変更してください。

アイテムの`custom_data:{"bot":{"lmb_hold":1}}`は変わり続けます。*

## 注意事項
他のブロックと重なった時左クリック検知が外れてしまいます。
重なるようなブロックはブロックディスプレイに置き換える、配布マップであれば、はしごなどの機能はブロックを一つclimableとするなど、各々対策するしかないです。
エンティティと重なると左クリックの検知が止まります。
石の採掘音が鳴ってしまいます。リソースパックで石の採掘音を消すか、上から大きな音で上書きしてください。*
左クリック長押し検知中はサバイバルモードになっています。普段がアドベンチャーモードなら、アイテムを持っていない時はアドベンチャーモードに戻ります。また、サバイバルモードになる影響で他のブロックが破壊されてしまうことは無いです。
左クリック長押し検知中、透明なブロックの枠線が出てしまいます。リソースパックなどで対策してください。*
